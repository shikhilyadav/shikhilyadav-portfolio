# SHIKHIL FLIX — AI, Machine Learning & Data Science Portfolio

> *"Explore my work. Discover my world."*

A modern, cinematic, Netflix-inspired portfolio web application designed and built for **Shikhil Yadav** (MCA scholar exploring Artificial Intelligence, Machine Learning, Data Science, and Software Development).

---

## 🌟 Key Features

- **Netflix-Inspired Streaming Interface**: Dark cinematic palette (`#141414` base with `#E50914` signature red accents), frosted sticky navigation, and smooth hover-preview cards.
- **Split Hero Showcase**: Dynamic split hero layout pairing candidate credentials with a high-impact cinematic featured banner for **IrisAI**.
- **Interactive Project Carousels**:
  - *Continue Exploring* (All featured works)
  - *Artificial Intelligence & Machine Learning* (Supervised classification & regression)
  - *Data & Analytics* (Exploratory data analysis & socioeconomic trend visualization)
  - *Natural Language Processing* (Comparative text classification with TF-IDF and BERT embeddings)
- **Live Search & Filter**: Instant header search filtering projects across titles, categories, and tags.
- **Deep-Dive Technical Modals**: Architectural walkthroughs featuring dataset context, engineering features, pipeline methodology, and evaluation benchmarks.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewing with mouse-drag carousel support and keyboard navigation.

---

## 🚀 Featured Engineering Projects

1. **IrisAI — Iris Flower Classification**
   - Multi-class morphological classification pipeline identifying Iris species (Setosa, Versicolor, Virginica) using Fisher's dataset.
2. **Unemployment Analysis — Data Analysis & Visualization**
   - Socioeconomic time-series analysis exploring regional unemployment fluctuations, labor participation rates, and COVID-19 pandemic impacts.
3. **AutoValue AI — Car Price Prediction**
   - Multivariate regression modeling engine estimating automobile valuations based on vehicle age, mileage, transmission, and fuel specifications.
4. **SpamShield AI — SMS Spam Detection**
   - Comparative NLP architecture contrasting classical machine learning (TF-IDF + Naive Bayes / SVM) against pretrained transformer (BERT) embeddings.

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/shikhilyadav/shikhilyadav-portfolio.git

# Navigate to project directory
cd shikhilyadav-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will run locally on `http://127.0.0.1:3005/` (or your configured Vite port).

### Building for Production

```bash
npm run build
```

The compiled assets will be output to the `dist/` directory.
