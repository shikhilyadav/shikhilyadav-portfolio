> *"Every project has a story. Every challenge creates a lesson."*

An immersive, cinematic interactive documentary portfolio designed and built for **Shikhil Yadav** (MCA candidate exploring Artificial Intelligence, Machine Learning, Data Science, and Software Development).

1. **Chapter 00 — The Opening**
   - Imposing editorial prologue introducing candidate identity, academic pursuit, and core engineering philosophy.
2. **Chapter 01 — The Beginning**
   - *“It started in college.”* — Chronicle of early explorations in programming logic, algorithms, and discovering the storytelling power of data.
3. **Chapter 02 — Curiosity & Exploration**
   - *“One interest led to another.”* — Interactive technology ecosystem spanning **Artificial Intelligence**, **Machine Learning**, **Data Science**, **Software Development**, and **Cybersecurity**.
4. **Chapter 03 — The Challenge**
   - *“Getting a model to work is only the beginning.”* — The realistic ML debugging and evaluation cycle:
     $$\text{DATA} \longrightarrow \text{MODEL} \longrightarrow \text{PREDICTION} \longrightarrow \text{EVALUATION}$$
     Covering the three stages: `01 Build` $\rightarrow$ `02 Investigate` $\rightarrow$ `03 Improve`.
5. **Chapter 04 — The Creations**
   - Interactive case studies and factual engineering showcases for four core projects.
6. **Chapter 05 — The Present**
   - Postgraduate academic pursuit (Master of Computer Applications) and verified **Oasis Infobyte Data Science Internship (OIBSIP)** milestones.
7. **Chapter 06 — The Next Chapter**
   - *“The story is still being written.”* — Earned credentials, future horizons, and direct communication channels.

## 🚀 Featured Engineering Case Studies

1. **IrisAI — Iris Flower Classification**
   - Multi-class morphological classification pipeline identifying Iris species (Setosa, Versicolor, Virginica) using Fisher's dataset.
2. **Unemployment Analysis — Data Analysis & Visualization**
   - Socioeconomic time-series analysis exploring regional unemployment fluctuations, labor participation rates, and COVID-19 pandemic impacts.
3. **AutoValue AI — Car Price Prediction**
   - Multivariate regression modeling engine estimating automobile valuations based on vehicle age, mileage, transmission, and fuel specifications.
4. **SpamShield AI — SMS Spam Detection**
   - Comparative NLP architecture contrasting classical machine learning (TF-IDF + Naive Bayes / SVM) against pretrained transformer (BERT) embeddings.

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/shikhilyadav/shikhilyadav-portfolio.git

# Navigate to project directory
cd shikhilyadav-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will run locally on `http://127.0.0.1:3005/` (or your configured Vite port).

### Building for Production

```bash
npm run build
```

Compiled assets will be output to the `dist/` directory.
